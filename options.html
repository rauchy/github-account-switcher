GitHub Account Switcher

This extension automatically switches your GitHub account based on the repository or organization you are visiting.

If you navigate to any repo under the "Organization URL", it will switch to the "Organization-Specific Account" account. If you navigate to any other repo, it will switch to the Personal account.

When enabled, the extension silently swaps your browser session cookies to switch accounts — no menus, no clicking, no visible transitions. On the very first switch (or if your session expires), it falls back to the menu click-through automatically and re-learns your session for next time. Disable this if you prefer to always see the switch happen through GitHub's UI.
